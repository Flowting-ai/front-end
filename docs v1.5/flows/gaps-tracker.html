Each row traces back to a real, grep/read-verified location in source — nothing here is inferred or guessed.

V1.5 — Built by aggregating structured findings reported back from a dedicated audit pass across all eight companion docs. Every doc's own "Missing / Unused / Hidden" subsections (one per page/section, right after "Floating panels & Help") are the source of truth — this tracker is a flattened index over them for triage, not a replacement. One exception: the four Agents-feature items marked not yet in doc below were confirmed via a separate investigation pass but not folded into agents-flow-diagram.html itself (the doc-editing pass re-investigated independently and found a different, non-overlapping set) — kept here so the finding isn't lost, worth a follow-up pass on that doc.
