# Primitives — full list

All design primitives defined in `src/styles/tokens/primitives.css` (196 tokens). Generated 2026-10-02.

- **Light** is the value in `primitives.css`. **Dark** is what the dark theme remaps the same variable to (`theme.css`, generated by `scripts/generate-dark-theme.mjs`); `—` means it is not remapped and is the same in both themes.
- **Uses** counts `var(--token …)` references in `src` (not hard-coded copies of the value). Zero means nothing references it yet.
- Use a token as `var(--neutral-700)`. Opacity variants are translucent versions of a base step, e.g. `--neutral-700-12` = `--neutral-700` at 12%.
